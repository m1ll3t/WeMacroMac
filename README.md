# WeMacroMac

使用 Swift / SwiftUI / AppKit 开发的原生 macOS 电动滑轨控制程序，内置景深与步长计算器。独立开发的第三方应用，与 WeMacro 官方没有隶属关系。

本项目使用 OpenAI Codex 开发。

## 系统与版本

- macOS 14+；当前应用包为 Apple Silicon 版本。
- **1.0** 已封版；**1.1** 当前开发版，新增拍摄中计算器、扩展键盘控制和单端点开始拍摄。
- 支持 HC-08 BLE、USB 串口及测试假设备。

## 使用

1. 允许蓝牙权限，关闭占用同一控制器的其他应用，选择 USB 或蓝牙后连接。自动连接可在设置中开关。
2. 无硬件可手动选择“测试假设备（模拟移动）”。
3. 设置步长、单位、运动后稳定与快门间隔。µm 为慢速档、mm 为快速档；按住快进/快退始终采用快速档。
4. 起点、终点可任意顺序设置。起点归零时同步换算已设终点。
5. 只设任意一个端点并移动后即可点击运行，自动以当前位置补齐另一端点。未移动或回到原位置时运行不可用。
6. 默认从终点向起点拍摄，可切换方向。支持每步多张、回差补偿、完成后返回及设备蜂鸣。
7. 运动中控制按钮有按压反馈，但忽略操作，不发送或累积指令。停止按钮仍有效。
8. 拍摄中仍可打开计算器查看或计算；应用新步长在拍摄期间禁用。

计算器包括微距镜头、AKSEN 1–5×、AKSEN 5–10×和显微物镜；相机机型为全局设置并记住上次选择。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| ↑ / ↓ | 后退 / 前进 1 步；按住按当前步长和速度连续步进，松开后完成当前一步停止 |
| ← / → | 按住连续快退 / 快进，松开发送停止请求 |
| Page Up / Page Down | 后退 / 前进 10 步 |
| Home / End | 设置起点 / 终点 |
| Shift + Home / Shift + End | 回到起点 / 终点 |
| Delete / 退格 | 清除起终点和拍摄统计，保留参数 |
| Insert | 打开步长计算器，拍摄中可用 |
| ⌘ + Return | 运行拍摄 |
| Esc | 请求停止 |

快捷键在应用前台、未编辑输入框且未显示应用弹窗时生效；编辑文本保留按键原有功能。忙碌时忽略移动、设点和清空操作。

## 控制与计算说明

位置按运动脉冲累计，不是传感器测距。连续快速移动中途停止的位移按时间估算。当前不提供软件行程限制。

控制器运动回复与相机拍摄成功是不同的事件：目前未确认相机成功拍摄回传，张数及进度按已发送的快门指令同步更新。不同固件的完整回复格式仍需进一步核对。

景深与采样使用近似公式及用户提供的参考表。AKSEN 使用表格 NA，并对中间倍率插值；微距使用独立几何模型。实际拍摄需结合曝光、镜头及振动情况调整。

## 构建与测试

需要 Swift 6.2+ 及 macOS 开发工具。项目已包含 `Packages/WeMacroDOF`，不依赖开发者电脑上的其他目录。

```sh
./build-app.sh
./scripts/test.sh
```

应用输出到 `dist/WeMacro 1.1.app`。构建按当前 Mac 架构生成，使用本地签名，未经过 Apple 公证。

测试采用模拟设备，并关闭测试中的启动扫描和参数保存，不操作真实硬件。

## 目录

- `Sources/WeMacroMac`：UI、控制器、蓝牙/串口、快捷键及集成计算器。
- `Packages/WeMacroDOF`：光学计算、镜头参考表、机型数据及测试。
- `Tests`：协议和模拟流程测试。
- `Resources`：应用图标。
