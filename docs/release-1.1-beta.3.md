# WeMacro 1.1 Beta 3

## 更新内容

- 拍摄完成后保留上次起终点和绿色“已完成”状态。
- 打开步长计算器、设置、修改参数或单独试拍不会清除端点；再次手动移动后清除上一轮端点与拍摄统计，等待重新设置。
- 默认重叠率统一为 **20%**，各镜头页面一致。
- 结果区采用等宽两列，显示“景深”和“建议步长”。
- 不包含优化系数，建议步长直接用于应用，仍按 µm 整数、mm 一位小数向下取整。

## 下载

- `WeMacro-1.1-AppleSilicon.zip`：macOS 应用，适用于 macOS 14+、Apple Silicon（M 系列）。
- `WeMacro-1.1-source.zip`：本版对应的完整源码，包含构建脚本及测试。
- `SHA256SUMS.txt`：文件校验值。

版本号1.1.0，构建号112。应用本地签名，未经过Apple公证。原有Beta 1和Beta 2保留。

## 测试范围

发布前重新运行全部自动测试：**19项控制器及模拟流程测试、13项光学计算测试，共32项通过**。

覆盖端点保留、修改设置与试拍不清零、手动移动后清零、单端点自动补齐、双向拍摄、按键连续步进、忙碌操作丢弃、快门张数、CRC、镜头参考数据、默认20%重叠率等。测试使用模拟设备，关闭启动扫描与参数保存；本轮未驱动真实滑轨或相机。

进度与剩余张数仍按发送的快门指令计数，不代表确认相机保存成功。连续快速移动中途停止的位置按时间估算。
